# PatternFly playground

Throwaway Vite + React + TypeScript sandbox with PatternFly 6 prewired.

## Local

```bash
npm install
npm run dev
```

Edit `src/App.tsx` to try components.

## Make this a CodeSandbox template

1. Create a new GitHub repo (public is easiest for sharing).
2. Push this project:

```bash
git remote add origin git@github.com:<you>/patternfly-playground.git
git push -u origin main
```

3. On GitHub: **Settings → General → Template repository** → enable.
4. Open in CodeSandbox:

```text
https://codesandbox.io/p/github/<you>/patternfly-playground
```

Anyone can fork from that URL (or from **Use this template** on GitHub). The `.codesandbox/tasks.json` file installs deps and starts `npm run dev` automatically.

### Optional: import without publishing first

In CodeSandbox: **Import from GitHub** and paste the repo URL after you push.
